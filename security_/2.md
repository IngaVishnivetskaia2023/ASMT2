## Same origin

App uses ALB as a single entry point. 
ECS service behind ALB serves both the React SPA (static files) and FastAPI (API endpoints) from the same domain. 
Browser sees one origin for everything — no CORS needed. 
All internal services (OpenSearch, RDS, Redis, SageMaker, LLM) are in private VPC, accessed only by FastAPI inside ECS, never exposed to browser directly.

```
┌──────────────────────────────────────────────────────┐
│                                                      │
│  Origin = scheme + host + port                       │
│                                                      │
│  React SPA loaded from:  https://myapp.com (443)     │
│  API calls go to:        https://myapp.com (443)     │
│                          ───────────────             │
│                          same    same    same         │
│                          scheme  host    port         │
│                                                      │
│  = SAME ORIGIN                                       │
│                                                      │
│  ALB is the single gateway that makes this possible  │
│  Behind ALB: could be 10 different services           │
│  Browser doesn't know, doesn't care                  │
│                                                      │
└──────────────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────────┐
│  Tool         │  Evidence                       │
├───────────────┼─────────────────────────────────┤
│  Vite         │  /assets/ path, short hash      │
│  React        │  SPA, single index.html         │
│  FastAPI      │  Server: uvicorn, /api/v2/      │
│  ALB          │  everything on mydomain.net      │
│  Google Fonts │  only external dependency        │
└───────────────┴─────────────────────────────────┘
```

```
Time →

HTML     ██
          └─ browser parses, finds references to JS, CSS
JS          ████████
CSS         ██████
              └─ browser parses CSS, finds font reference
Fonts           ████ (cross-origin → fonts.googleapis.com)
Logo            ██
                └─ React rendered, triggers API call  
API               ████ mydomain.net/api/v2/settings
                    └─ response → React updates UI
```
