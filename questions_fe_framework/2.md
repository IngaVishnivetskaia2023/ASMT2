#### Angular's Advantage & Disadvantage
```
ADVANTAGE:
  "Batteries included" — one framework, one way to do things.
  New developer joins → same architecture everywhere.
  No "which router? which state lib? which form lib?" decisions.

DISADVANTAGE:
  • Heavier, more opinionated
  • RxJS learning curve is steep
  • No built-in TanStack-like caching (must build or add)
  • Boilerplate for simple things
  • Less flexible than React's "pick your stack"

```

Angular provides HTTP, routing, forms, DI, and reactive streams (RxJS) out of the box — services with Observables cover most state management needs without external libraries. NgRx is added only for complex enterprise apps needing Redux-like patterns. 
React requires assembling these pieces from separate libraries, giving more flexibility but more decision overhead.
