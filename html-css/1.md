### HTML Coding Principles

#### Semantic Structure Mental Map

```
<!DOCTYPE html>                    ← Tells browser: HTML5 mode
<html lang="en">                   ← Root + accessibility
<head>
  ├── <meta charset="UTF-8">      ← Character encoding
  ├── <meta name="viewport"...>   ← Responsive viewport
  ├── <title>                      ← SEO + tab title
  ├── <link rel="stylesheet">     ← External CSS
  └── <script defer>               ← External JS
</head>
<body>
  ├── <header>                     ← Landmark
  │     └── <nav>                  ← Navigation landmark
  ├── <main>                       ← Primary content
  │     ├── <section>              ← Thematic grouping
  │     ├── <article>              ← Self-contained
  │     └── <aside>                ← Sidebar
  ├── <footer>                     ← Footer landmark
  └── <script>                     ← Inline JS (bottom)
</body>
</html>
```

#### Three Ways to Include Scripts
```
┌──────────────────────────────────────────────────────────┐
│                                                          │
│  ① INLINE SCRIPT                                        │
│  ════════════════                                        │
│  <script>                                                │
│    const x = document.getElementById('app');             │
│    x.textContent = 'Hello';                              │
│  </script>                                               │
│                                                          │
│  ✅ Quick prototyping                                    │
│  ❌ No caching, no reuse, hard to test                   │
│  ❌ Blocks HTML parsing                                  │
│                                                          │
│                                                          │
│  ② INTERNAL SCRIPT (embedded but structured)             │
│  ════════════════════════════════════════════             │
│  <head>                                                  │
│    <script type="text/javascript">                       │
│      function init() { /* ... */ }                       │
│    </script>                                             │
│  </head>                                                 │
│                                                          │
│  ✅ No extra HTTP request                                │
│  ❌ Same problems: no caching, not reusable              │
│  ❌ Blocks parsing (unless in body end)                  │
│                                                          │
│                                                          │
│  ③ EXTERNAL SCRIPT ⭐ (best practice)                   │
│  ══════════════════                                      │
│  <script src="app.js"></script>                          │
│  <script src="app.js" defer></script>                    │
│  <script src="app.js" async></script>                    │
│                                                          │
│  ✅ Cached by browser                                    │
│  ✅ Reusable across pages                                │
│  ✅ Separation of concerns                               │
│  ✅ Testable independently                               │
│                                                          │
└──────────────────────────────────────────────────────────┘
```


#### Script Loading: default vs defer vs async

```
HTML PARSING TIMELINE:
══════════════════════

DEFAULT <script src="app.js">
──────────────────────────────
HTML: ████████ ⏸️STOP          ████████
JS:              ↓fetch↓execute↑
                 BLOCKS PARSING!


ASYNC <script async src="app.js">
──────────────────────────────────
HTML: ████████████████ ⏸️  ████████
JS:        ↓fetch↓────execute↑
           parallel   blocks when ready
           fetch      ORDER NOT GUARANTEED


DEFER <script defer src="app.js"> ⭐ BEST
──────────────────────────────────────────
HTML: ████████████████████████████
JS:        ↓fetch↓──────────────execute
           parallel             after DOM ready
           fetch                ORDER GUARANTEED


┌────────────┬───────────┬───────────┬──────────────┐
│            │  default  │  async    │  defer ⭐     │
├────────────┼───────────┼───────────┼──────────────┤
│ Blocks     │  YES ❌   │ On exec   │  NO ✅       │
│ parsing    │           │           │              │
├────────────┼───────────┼───────────┼──────────────┤
│ Exec order │ Sequential│ Random ❌ │ Sequential ✅│
│ guaranteed │           │           │              │
├────────────┼───────────┼───────────┼──────────────┤
│ Waits for  │  NO       │  NO      │  YES ✅      │
│ DOM ready  │           │           │              │
├────────────┼───────────┼───────────┼──────────────┤
│ Use for    │ Legacy    │ Analytics │ App code ⭐  │
│            │           │ 3rd party │              │
└────────────┴───────────┴───────────┴──────────────┘
```

#### Three Ways to Include CSS
```
┌──────────────────────────────────────────────────────────┐
│                                                          │
│  ① INLINE STYLES                                        │
│  ════════════════                                        │
│  <p style="color: red; font-size: 16px;">Text</p>       │
│                                                          │
│  ✅ Highest specificity (overrides everything)           │
│  ✅ Quick testing/debugging                              │
│  ❌ No reuse, no pseudo-classes/elements                 │
│  ❌ No media queries                                     │
│  ❌ Mixes concerns                                       │
│                                                          │
│  Specificity: 1,0,0,0                                    │
│                                                          │
│                                                          │
│  ② INTERNAL CSS (embedded <style>)                       │
│  ═════════════════════════════════                        │
│  <head>                                                  │
│    <style>                                               │
│      .card { color: red; padding: 16px; }                │
│      .card:hover { background: blue; }                   │
│    </style>                                              │
│  </head>                                                 │
│                                                          │
│  ✅ Supports all CSS features                            │
│  ✅ No extra HTTP request                                │
│  ✅ Good for critical CSS / above-the-fold               │
│  ❌ Not cached separately                                │
│  ❌ Not reusable across pages                            │
│                                                          │
│                                                          │
│  ③ EXTERNAL CSS ⭐ (best practice)                      │
│  ══════════════════                                      │
│  <head>                                                  │
│    <link rel="stylesheet" href="styles.css">             │
│  </head>                                                 │
│                                                          │
│  ✅ Cached by browser                                    │
│  ✅ Reusable across pages                                │
│  ✅ Separation of concerns                               │
│  ✅ Testable, lintable                                   │
│  ⚠️ Render-blocking (browser waits for CSSOM)            │
│                                                          │
└──────────────────────────────────────────────────────────┘
```

#### CSS Specificity Quick Reference
```
SPECIFICITY HIERARCHY (low → high):

  ┌─────────────────────────────────────────────┐
  │                                             │
  │  * { }                    →  0,0,0,0        │
  │  element (div, p)         →  0,0,0,1        │
  │  .class                   →  0,0,1,0        │
  │  #id                      →  0,1,0,0        │
  │  inline style=""          →  1,0,0,0        │
  │  !important               →  ∞ (overrides)  │
  │                                             │
  └─────────────────────────────────────────────┘
```

#### HTML5 Validation Attributes
```
<input
  type="email"
  required                    ← Must fill
  minlength="3"               ← Min characters
  maxlength="50"              ← Max characters
  pattern="[a-z]+@[a-z]+\."  ← Regex pattern
  placeholder="you@mail.com"  ← Hint text
  autocomplete="email"        ← Browser autofill
/>

<input
  type="number"
  min="0"                     ← Minimum value
  max="100"                   ← Maximum value
  step="5"                    ← Increment step
/>

<input
  type="file"
  accept=".png,.jpg"          ← File type filter
  multiple                    ← Allow multi-select
/>
```

#### Testing Context: HTML/CSS in Automation

```
┌────────────────────────────────────────────────────────┐
│                                                        │
│  SELECTOR STABILITY PYRAMID                            │
│                                                        │
│          ❌ FRAGILE                                     │
│           /\                                           │
│          /  \  cy.get('.btn-primary')                   │
│         /    \   ↑ breaks when class changes            │
│        /      \                                        │
│       / TEXT   \ cy.contains('Submit')                  │
│      /          \  ↑ breaks when text changes           │
│     /            \                                     │
│    /   STRUCTURE  \ cy.get('div > form > button:nth')  │
│   /                \  ↑ breaks when DOM changes         │
│  /                  \                                  │
│ / ⭐ data-testid    \ cy.get('[data-testid="submit"]') │
│ ──────────────────────  ✅ STABLE, decoupled           │
│                                                        │
└────────────────────────────────────────────────────────┘
```
